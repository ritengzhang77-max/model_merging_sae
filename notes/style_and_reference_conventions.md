# Style and Reference Conventions

When discussing papers in this project, include more than just the paper title.
Use this format whenever practical:

```text
Authors, "Title," venue or arXiv/preprint, year.
```

If the paper has no known peer-reviewed venue, say `arXiv preprint`.
If the venue is uncertain, mark it as `venue uncertain` rather than guessing.

Also include citation count when it matters for prioritizing or describing
influence. Citation counts are time-varying, so do not treat them as static
memory. Look them up from a source such as Semantic Scholar, OpenAlex, Google
Scholar, or the venue page, and state the source/date if giving a number.
